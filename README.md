# 溜溜的个人主页

一个无需安装依赖的静态网站，包含个人介绍、学习情况、GitHub 项目、五本小说和五首歌曲。

当前设计使用用户提供的 MoltenMetal 紫、粉、白三色动态光效作为全屏背景，并保留暗色遮罩。电脑主页按参考图排列：左侧为无白底的圆形猫头像、昵称、介绍框和四个快捷链接；右侧上方为四行事件倒计时与日期时钟，下方为三列、两行的六个入口。六个入口包括四个文件夹、“个人简介”和“下载简介”。卡片使用较淡的半透明背景。手机按屏幕尺寸调整排列。

四个文件夹为学习记录、我的项目、我的书架、我的歌单。普通电脑主页保持一屏。小屏、短横屏或放大文字后，空间不足时可纵向滚动，避免裁切内容。长内容放在详情窗口中，可单独滚动。

文件夹交互参考用户提供的 FolderFloat 示例，使用 HTML、CSS 和 JavaScript 实现，无需安装 React 或物理引擎。网站仍处于本地验收阶段，尚未上传或发布。

## 先看效果

双击 `index.html`，即可在浏览器打开。保持 `profile.txt` 与它位于同一个文件夹，并保留整个 `assets` 文件夹，以加载壁纸、样式、交互和项目图表。

## 使用文件夹

- 电脑：鼠标移到文件夹上，选项会浮出。鼠标在文件夹按钮、展开选项和两者之间移动时保持展开；移到其他区域或移出浏览器窗口时自动收起。选择选项、切换文件夹、点击空白处或按 Escape，也可以收起。
- 手机：点击文件夹，打开或关闭选项。
- 点击“个人简介”，查看完整介绍。点击学习选项，查看对应记录。
- 左侧信封图标用于写邮件，悬停可查看 QQ 邮箱。邮箱地址也显示在“个人简介”中，并已加入下载简介。
- 点击项目选项，查看项目介绍、输出图表和源码链接。
- 点击小说封面或书名，查看对应的封面大图。
- 点击歌曲选项，在新标签页打开网易云音乐搜索。
- 点击倒计时卡片的“编辑”，可以分别修改四个事件的名称和日期。按北京时间计算，显示剩余天数、就是今天或已过天数。
- 点击“保存”后，设置保存在当前浏览器；刷新后仍保留。取消、关闭编辑或按 Escape 不保存草稿。更换浏览器、设备或清除网站数据后不会保留；其他访客也不会同步获得这些设置。
- 右上时钟显示北京时间，每秒更新。
- 键盘：用 Tab 选择文件夹。按 Enter 或空格展开，再用 Tab 选择选项。按 Escape 收起文件夹或关闭详情。
- 如果鼠标移出时，键盘焦点仍在文件夹选项中，焦点会回到对应文件夹按钮。
- 打开详情时，地址栏会显示对应的 `#` 地址。复制地址可直接访问详情。浏览器返回可关闭详情，前进可重新打开。Ctrl/Cmd 点击和中键点击保留浏览器的新标签页操作。
- 手机上的小图标和文字入口使用至少 44px 的点击范围。图标大小与入口顺序保持不变。
- 页脚的“暂停动画”按钮可暂停壁纸和三个星星卡片。再点击“恢复动画”可继续。暂停期间，时钟、歌单和文件夹仍可操作。
- 打开详情窗口时，壁纸和三个星星卡片暂时停止动画。关闭详情后恢复原来的状态；用户手动暂停或系统设置了减少动态效果时，仍保持静止。
- 系统设置了“减少动态效果”时，展开和收起不使用动画。

介绍框、倒计时框和时钟框保留星星 HoloCard 效果。MoltenMetal 背景缓慢流动，并随鼠标轻微偏移；背景不接收点击，不影响链接和文件夹操作。页面不可见时，动画暂停。系统设置了“减少动态效果”时，壁纸和卡片显示静止光效，页脚按钮显示“系统静态”。浏览器未运行 JavaScript 时，网页会显示普通链接和完整内容。

详情窗口可独立滚动，滚动到边界时不会继续滚动外层页面。页面为手机刘海和底部手势条预留安全区。真实手机的 Safari 显示效果和动画性能仍需实机检查。

动态背景代码为 `assets/molten-metal.js`，沿用用户提供的 MoltenMetal 着色器和示例参数，改为原生 WebGL2 实现，无需安装 React 或 ogl。设备像素比上限为 2。浏览器不支持 WebGL2 或渲染失效时，页面使用深色底色。旧照片 `assets/wallpaper.jpg` 仅保留为历史素材，页面不再显示或加载它。

项目区展示 `gubanqi/data-analysis-tool` 的功能和仓库中已有的平均分图表。当前仓库为私有，源码链接需要访问权限；本次网站修改未改变仓库可见性。

歌曲链接用于在网易云音乐搜索歌名，未指定歌手、版本或直接播放地址。歌曲搜索可能需要登录或受平台访问条件影响。

## 免费发布到 GitHub Pages

1. 登录准备使用的 GitHub 账号 `gubanqi`，核对右上角账号菜单中的用户名。
2. 在 `gubanqi` 账号下新建公开仓库，仓库名为 `gubanqi.github.io`。如果这个仓库已经存在，先查看里面的内容，避免覆盖已有网站。
3. 点击 **Add file → Upload files**，将本文件夹中的 `index.html`、`profile.txt` 和整个 `assets` 文件夹上传到仓库根目录并提交。不要只上传 ZIP 压缩包，也不要多套一层文件夹。
4. 打开仓库 **Settings → Pages**。
5. 在 **Source** 选择 **Deploy from a branch**，选择 `main` 分支和 `/ (root)`，点击 **Save**。如果上传后实际分支名不同，则选择包含网站文件的分支。
6. 等待 GitHub 显示发布成功，打开 `https://gubanqi.github.io/`。这是计划使用的网址，当前文件准备完成不代表网站已上线。官方说明发布更新可能需要最多约 10 分钟。
7. 用手机和电脑各打开一次，检查字体、导航、歌曲搜索和文字简介下载，然后再把链接发给老师。

以后在同一个仓库修改文件并提交，网页会更新，网址一般不变。

GitHub 官方步骤：https://docs.github.com/en/pages/quickstart

## 给 GPT 使用

可将网站链接发给 GPT，并说明“请读取这个网页，作为我当前的个人背景”。若具体网页无法读取，直接上传或粘贴 `profile.txt`。
